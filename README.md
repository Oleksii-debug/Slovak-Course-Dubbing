# Slovak-Course-Dubbing

Українське озвучення багатомовних аудіозанять зі словацької мови.

Російські пояснення перекладаються українською, а словацькі навчальні приклади зберігаються словацькою. Обидві частини використовують наявний профіль **«Олексій 2» (oleksii_day1)** із dordiai-voices. Повтори, порядок прикладів і паузи для відповіді мають залишатися придатними для навчання.

## Стан

Підготовлено **повну тестову версію уроку №575 для прослуховування**: 103 українські й 135 словацьких мовленнєвих фрагментів, усі 16 завдань і бонус. Голос — «Олексій 2». Складання перевіряє кожен фрагмент, порядок, тривалість і контрольні суми. Аудіо й матеріали уроку передаються приватно; у цьому репозиторії міститься код.

Вибіркове повторне розпізнавання перевірило українські й словацькі фрази. Це не засвідчує безпомилкову вимову всього запису: у фінальному вірші автоматичне розпізнавання слова `dolu` лишилося неоднозначним навіть після поліпшення мовного контексту. Природність голосу й комфорт слухання оцінюються на повному аудіо.

Це команди для керованої обробки вже перевіреного тексту. Автоматичний переклад і багатомовна транскрипція без перевірки тут не заявлені готовими. Первинне розпізнавання плутало мови: словацький режим записував російські пояснення латинкою, а російський — словацькі приклади кирилицею. Тому потрібні **перевірений транскрипт, мовні межі та український переклад**. Нерозбірливі слова не можна замінювати здогадками або перекладати весь урок одним запитом.

Для цього пілоту перевірені українська та словацька. Англійські приклади входять до цілі проєкту, але окремий наскрізний шлях для них ще не прийнятий.

## Перевірений спосіб озвучення

1. Українські пояснення читає **рідна модель Holos** із профілем «Олексій 2».
2. Перевірений словацький текст спочатку читає **en-US-BrianMultilingualNeural** через доступний сервіс мовлення Edge.
3. Чистий словацький синтез перетворюється через **OpenVoice V2** у той самий збережений профіль «Олексій 2».
4. Гучність фрагментів вирівнюється, після чого вони збираються в MP3.

На словацькому контрольному прикладі розпізнавання без текстової підказки відновило всі три речення і до, і після перетворення голосу. Український Holos зберіг перевірені речення та числа 575, 15, 30, 60. Це перевірка розбірливості окремих фрагментів; подібність тембру між двома гілками та комфорт готового заняття ще потребують прослуховування.

Два випробувані варіанти **не використовуються у фінальному шляху**:

- Пряма заміна голосу оригінального викладача через OpenVoice погіршила розбірливість словацької. Відхилені результати не можна підмішувати до уроку.
- Brian не пройшов перевірку української вимови, тому українські пояснення озвучує Holos.

Походження коду, моделей, їхні контрольні суми та результати проб описані в [docs/VOICE_BACKEND.md](docs/VOICE_BACKEND.md). Синтезатор не навчається з нуля.

## Середовище та ресурси

Перевірене середовище обробки: **Linux, Python 3.12, CPU**, ffmpeg, ffprobe. Рекомендовано окреме Python-середовище:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-voice.lock.txt
```

Потрібні вже підготовлені приватні ресурси dordiai-voices:

- Каталог початкового Python-runtime dordiai-voices.
- Каталог моделей Holos/OpenVoice і профілів «Олексій 2».
- Чисті Python-пакети holos_onnx, ipa_uk, ukrainian_word_stress із його словником. Вони походять із наявного пакета синтезатора.
- Представницький словацький аудіозразок саме того голосу Brian, який використовується для проміжного словацького синтезу.

Точний snapshot коду й походження приватного ядра зафіксовані в документації бекенда. **Моделі та особисті голосові дані не входять до публічного Git.** Встановлення Python-залежностей саме по собі не завантажує ці ресурси.

Для команд нижче налаштуйте робочі шляхи. Це приклади розташування, а не посилання на конкретні користувацькі файли:

```bash
DUBBING_RUNTIME_SOURCE=voices/dordiai-runtime
DUBBING_MODELS=models/dordiai
DUBBING_EXTRAS=voices/dordiai-python-packages
DUBBING_SOURCE_REFERENCE=voices/brian-sk-reference.wav
```

Якщо копія Holos містить Windows-операції Snake, підготуйте **робочу копію** моделі для Linux. Скрипт залишає оригінальні ONNX і DLL під окремими іменами:

```bash
.venv/bin/python scripts/prepare_linux_holos.py --models "$DUBBING_MODELS"
```

Гілки Holos і OpenVoice працюють локально. Словацький TTS звертається до сервісу Edge і надсилає тільки перевірений словацький текст; початковий запис викладача й приватні моделі туди не передаються. Доступність зовнішнього сервісу може змінюватися, тому готові фрагменти кешуються з контрольними сумами.

У перевіреному середовищі використано HTTPS_PROXY; SOCKS і пакети aiohttp-socks/python-socks не встановлювалися. Якщо середовище задає CODEX_PROXY_CERT, скрипт додає саме цей сертифікат до довірених, зберігаючи перевірку TLS. Значення проксі, сертифікати та облікові дані в Git не додаються.

## 1. Підготувати перевірені фрагменти

Команди відтворюваного розпізнавання та його залежності описані в [docs/TRANSCRIPTION.md](docs/TRANSCRIPTION.md). Перетворіть вхідне аудіо на моно WAV 24 кГц. Оригінал залишається окремо:

```bash
mkdir -p work/lesson outputs
ffmpeg -hide_banner -loglevel error -i inputs/lesson.mp3 \
  -ac 1 -ar 24000 -c:a pcm_s16le work/lesson/source.wav
```

Файл work/lesson/reviewed_spans.json — JSON-масив з унікальними ідентифікаторами, початковими часовими межами та перевіреним текстом. Початок і кінець задаються у секундах оригіналу. Фрагменти впорядковані за часом і не перекриваються. Приклад формату з вигаданими часовими межами:

```json
[
  {
    "id": "s001",
    "start": 1.0,
    "end": 4.0,
    "source_language": "ru",
    "language": "uk",
    "text": "Сьогодні ми вивчаємо словацьку мову.",
    "mode": "tts"
  },
  {
    "id": "s002",
    "start": 4.5,
    "end": 7.0,
    "source_language": "sk",
    "language": "sk",
    "text": "Dobrý deň. Ako sa máte?",
    "mode": "tts_convert"
  }
]
```

У словацьких записах mode=tts_convert позначає обраний шлях: synthesize_slovak.py озвучує перевірений текст, а convert_tts_chunks.py перетворює отриманий чистий синтез. Такі записи не передаються в пряму конвертацію оригіналу.

Створіть окремий маніфест тільки українських пояснень:

```bash
.venv/bin/python - <<'PY'
import json
from pathlib import Path
root = Path("work/lesson")
rows = json.loads((root / "reviewed_spans.json").read_text(encoding="utf-8"))
uk = [row for row in rows if row["language"] == "uk"]
assert uk and all(row["mode"] == "tts" for row in uk)
(root / "uk_spans.json").write_text(json.dumps(uk, ensure_ascii=False, indent=2), encoding="utf-8")
PY
```

## 2. Озвучити українські пояснення

```bash
.venv/bin/python scripts/synthesize_spans.py \
  --source work/lesson/source.wav \
  --segments work/lesson/uk_spans.json \
  --output-dir work/lesson/uk_chunks \
  --runtime "$DUBBING_RUNTIME_SOURCE" \
  --models "$DUBBING_MODELS" \
  --extras "$DUBBING_EXTRAS" \
  --profile oleksii_day1 --threads 2 \
  --reference-start 16.14 --reference-end 50.0
```

Межі 16.14–50.0 належать використаному пілотному запису. Для іншого уроку задайте дійсний інтервал чистого мовлення викладача без музики. Цей технічний адаптер ще створює вектор оригінального голосу, хоча при маніфесті лише з mode=tts українське аудіо читає Holos, а пряме перетворення не виконується.

Вихід — ID.wav і manifest.json. Повторний запуск використовує тільки готові фрагменти, для яких збігаються джерело, моделі, текст і фактичний WAV.

## 3. Озвучити словацькі приклади

```bash
.venv/bin/python scripts/synthesize_slovak.py \
  --segments work/lesson/reviewed_spans.json \
  --output-dir work/lesson/sk_tts \
  --voice en-US-BrianMultilingualNeural --concurrency 2
```

Скрипт вибирає тільки словацькі записи. Короткі слова на кшталт sa, si, a озвучуються зі словацьким вступом для визначення мови; вступ видаляється за поверненими часовими мітками слів. Для довшої фрази з неоднозначною вимовою можна явно задати `"tts_prefix": "Po slovensky poviem: "`. Якщо межу вступу неможливо визначити надійно, скрипт завершується помилкою. Сирий MP3, метадані та очищений ID.wav залишаються в приватній робочій папці.

Перетворіть **очищені WAV**, а не сирі MP3 зі вступом, у профіль «Олексій 2»:

```bash
.venv/bin/python scripts/convert_tts_chunks.py \
  --input-dir work/lesson/sk_tts \
  --segments work/lesson/reviewed_spans.json \
  --output-dir work/lesson/sk_converted \
  --source-reference "$DUBBING_SOURCE_REFERENCE" \
  --extension .wav \
  --runtime "$DUBBING_RUNTIME_SOURCE" \
  --models "$DUBBING_MODELS" \
  --extras "$DUBBING_EXTRAS" \
  --profile oleksii_day1 --threads 2
```

Один вхідний фрагмент має тривати не більше 30 секунд. Довші приклади потрібно заздалегідь поділити за реченнями, зберігши порядок і весь зміст.

## 4. Вирівняти гучність

Об'єднайте тільки прийняті гілки: українські uk_chunks і словацькі sk_converted. Наступна команда готує спільний маніфест та шляхи для складання; вона не використовує відхилену пряму конвертацію оригіналу:

```bash
.venv/bin/python - <<'PY'
import json, shutil
from pathlib import Path
root = Path("work/lesson")
rows = json.loads((root / "reviewed_spans.json").read_text(encoding="utf-8"))
folders = {"uk": root / "uk_chunks", "sk": root / "sk_converted"}
manifests = {lang: json.loads((folder / "manifest.json").read_text()) for lang, folder in folders.items()}
speech = root / "speech"
speech.mkdir(exist_ok=True)
records, assembly = {}, []
for row in rows:
    lang, name = row["language"], str(row["id"])
    if lang not in folders:
        raise ValueError("Мову ще не прийнято для цього шляху: " + lang)
    record = manifests[lang]["segments"][name]
    if record["text"] != row["text"]:
        raise ValueError("Застарілий синтез: " + name)
    shutil.copyfile(folders[lang] / (name + ".wav"), speech / (name + ".wav"))
    records[name] = record
    assembly.append({**row, "audio_path": "normalized/" + name + ".wav"})
combined = {"identity": {lang: value["identity"] for lang, value in manifests.items()}, "segments": records}
(speech / "manifest.json").write_text(json.dumps(combined, ensure_ascii=False, indent=2), encoding="utf-8")
(root / "assembly.json").write_text(json.dumps(assembly, ensure_ascii=False, indent=2), encoding="utf-8")
PY

.venv/bin/python scripts/normalize_chunks.py \
  --input-dir work/lesson/speech \
  --output-dir work/lesson/normalized \
  --target-rms 0.065 --peak-ceiling 0.95
```

Нормалізація застосовує один коефіцієнт підсилення до кожного фрагмента, оцінюючи активне мовлення. Частота 24 кГц, кількість семплів і тривалість залишаються незмінними. Оригінальні синтезовані файли не перезаписуються.

## 5. Зібрати MP3

```bash
DUBBING_SOURCE_SECONDS=$(ffprobe -v error -show_entries format=duration \
  -of default=noprint_wrappers=1:nokey=1 work/lesson/source.wav)

.venv/bin/python scripts/assemble_lesson.py \
  --manifest work/lesson/assembly.json \
  --source-duration "$DUBBING_SOURCE_SECONDS" \
  --natural-timing \
  --output outputs/lesson.mp3 \
  --timeline outputs/lesson.timeline.json
```

Складання зберігає початкову, кінцеву й міжфразові паузи. У режимі `--natural-timing` кожне речення звучить зі своєю природною тривалістю: до коротших фраз не додається штучна тиша. Без цього прапорця коротший синтез доповнюється тишею до старого інтервалу. Мовлення не прискорюється і не обрізається. Результат — моно MP3, 24 кГц, 128 кбіт/с і JSON з фактичними часовими мітками, контрольними сумами та перевіркою кожного ідентифікатора.

У пілотному файлі після складання застосовано загальне вирівнювання гучності ffmpeg `loudnorm=I=-18:TP=-1.5:LRA=11`, з повторним кодуванням у MP3 128 кбіт/с. Це не змінює послідовність або мовленнєвий зміст.

Скрипт не змішує фонову музику автоматично. Якщо перевірений вступ або інший немовленнєвий фрагмент треба зберегти, його додають у фінальний маніфест як окремий аудіозапис із точними межами, без перекриття мовлення.

## Перевірка

Після складання потрібні перевірка повноти, мовних меж, повторів і пауз, вибіркове повторне розпізнавання української та словацької, а також прослуховування готового заняття. ASR може помилятися; точний збіг тексту не доводить природність тембру або якість кожного слова.

Наявні тести перевіряють поведінку складання на синтетичних звукових фрагментах. Вони не підтверджують якість перекладу чи нейроголосу:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

## Приватні матеріали

У Git зберігаються тільки код, залежності та інструкції. Оригінальні уроки, зразки голосів, моделі, транскрипти, переклади й результати обробки залишаються поза публічним репозиторієм. Для них передбачені виключені через .gitignore каталоги inputs/, voices/, models/, work/, outputs/.

Готовий аудіофайл передається користувачеві окремо після перевірки. Жодні особисті голосові дані, надіслані уроки або приватні посилання в приклади не включені.

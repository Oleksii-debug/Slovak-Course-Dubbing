# Slovak-Course-Dubbing

Українське озвучення багатомовних занять зі словацької мови з наявним профілем **«Олексій 2» (`oleksii_day1`)** із dordiai-voices.

Російські пояснення перекладаються українською. Порівняння між мовами адаптуються за змістом: українські відповідники, рід і граматичні конструкції можуть відрізнятися від російських. Словацькі й англійські навчальні приклади зберігають свою мову. Повтори, порядок пояснень і паузи для учня залишаються частиною заняття.

## Стан

Перший повний пілот — урок №575. Після відгуку слухача обробку наступного уроку №576 змінено: окремий словацький голос, явні українські наголоси, виправлені паузи, очищення немовленнєвих меж синтезу, справжні звуки клавіатури та наближене відтворення акустики кімнати.

Перевірений сценарій уроку №576 містить 377 фрагментів: 300 словацьких, 68 українських і 9 англійських. Українські наголоси звірені окремо; відновлено пропущені первинним ASR короткі пояснення. Три нерозбірливі місця оригіналу та прийняті змістові рішення зафіксовано у приватному журналі.

Аудіо, транскрипти, голосові профілі й моделі передаються приватно. У цьому публічному репозиторії містяться код та опис відтворюваного процесу.

Це керована обробка **перевіреного тексту**. Автоматичний переклад цілого уроку без редактури тут не заявлений готовим. Мови часто змінюються всередині речення; ASR може записати російське пояснення словацькою латинкою або перекласти словацький приклад російською. Потрібні окремі мовні проходи, перевірка контексту і точні межі прикладів.

## Поточний спосіб озвучення

| Частина | Синтез і обробка |
| --- | --- |
| Українські пояснення | Holos із профілем «Олексій 2»; перевірені наголоси, керовані паузи, очищення тільки відомих немовленнєвих ділянок |
| Словацькі приклади | `sk-SK-LukasNeural` → OpenVoice V2 → збережений профіль «Олексій 2» |
| Окремі англійські приклади | `en-US-GuyNeural` → OpenVoice V2 → той самий профіль; окремий референс базового англійського голосу |
| Фон і клавіатура | Справжні немовленнєві проміжки оригіналу та впевнено виділені короткі клацання; без суцільного підмішування старого викладача |
| Акустика | Тихий оригінальний фон і реверберація, наближена за виміряним затуханням; точна імпульсна характеристика кімнати не відновлена |

Назва голосового профілю відома, але в доступному пакеті немає первинного запису, який незалежно підтверджує особу мовця. Вибір профілю спирається на раніше обраний користувачем «Олексій 2».

Словацька модель замінює багатомовний Brian із першого пілоту. Нативна мовна модель, точна тривалість і успішне повторне розпізнавання **не є сертифікатом носійської вимови після перетворення тембру**. Особливої уваги потребують довгота голосних, м’якість, складотворчі приголосні й запозичення. Наявні активи Holos також не містять окремого навченого стилю «викладач»: поліпшення подачі тут забезпечують редактура, наголоси і ритм.

Докладніше: [голос і паузи](docs/TEACHING_VOICE.md), [фон і клавіатура](docs/SOUNDSCAPE.md), [походження моделей](docs/VOICE_BACKEND.md), [розпізнавання](docs/TRANSCRIPTION.md).

## Середовище

Перевірено на Linux, Python 3.12, CPU. Потрібні `ffmpeg` і `ffprobe`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-voice.lock.txt
```

Приватні ресурси dordiai-voices надаються окремо: runtime, моделі Holos/OpenVoice, відповідні голосові NPY, Python-пакети `holos_onnx`, `ipa_uk`, `ukrainian_word_stress` зі словником. Разом із голосовими даними збережіть `delivery_profiles.json`, `reference_prosody.json`, `ukrainian_articulation.json` та `delivery_equalizers.json` у `models/voices/`.

Робочі шляхи в прикладах:

```bash
DUBBING_RUNTIME_SOURCE=voices/dordiai-runtime
DUBBING_MODELS=models/dordiai
DUBBING_EXTRAS=voices/dordiai-python-packages
DUBBING_SLOVAK_REFERENCE=voices/lukas-sk-reference.wav
```

Якщо Holos містить Windows-операції Snake, підготуйте робочу копію для Linux:

```bash
.venv/bin/python scripts/prepare_linux_holos.py --models "$DUBBING_MODELS"
```

Holos і перетворення голосу працюють локально. Edge отримує тільки перевірений текст іншомовних прикладів. Початковий запис і приватні голосові моделі туди не надсилаються. Зовнішній сервіс потрібен для першого синтезу; кеш перевіряється за текстом, голосом, налаштуваннями та хешем WAV. За наявності `CODEX_PROXY_CERT` зберігається перевірка TLS з додаванням відповідного сертифіката.

## 1. Перевірений текст

`work/lesson/reviewed_spans.json` — впорядкований масив неперекривних фрагментів. Часові межі задаються у секундах **оригіналу**. Приклад із вигаданими межами:

```json
[
  {
    "id": "s001", "start": 1.0, "end": 4.0,
    "source_language": "ru", "language": "uk", "mode": "tts",
    "text": "Сьогодні ми вивчаємо словацьку мову.",
    "tts_text": "Сього́дні ми вивча́ємо слова́цьку мо́ву."
  },
  {
    "id": "s002", "start": 4.5, "end": 7.0,
    "source_language": "sk", "language": "sk", "mode": "tts_convert",
    "text": "Dobrý deň. Ako sa máte?"
  }
]
```

`tts_text` або `text_stressed` може додати українські наголоси, але не змінити слова. Зміст редагується у полі `text`. Непевні вихідні слова і змістові адаптації слід документувати окремо. Опис розпізнавання — у [TRANSCRIPTION.md](docs/TRANSCRIPTION.md).

## 2. Українська

```bash
.venv/bin/python scripts/teaching_voice.py \
  --segments work/lesson/reviewed_spans.json \
  --output-dir work/lesson/uk_chunks \
  --runtime "$DUBBING_RUNTIME_SOURCE" --models "$DUBBING_MODELS" \
  --extras "$DUBBING_EXTRAS" --profile oleksii_day1 --threads 2
```

Скрипт вибирає українські фрагменти. Зберігає WAV, фактичні фонемні тривалості, наголоси та ділянки очищення. Остання пунктуаційна пауза фрагмента коротша за внутрішню паузу між реченнями: додаткова довга тиша не накладається на початкові паузи заняття. Невирішені наголоси треба перевірити перед складанням.

## 3. Словацька й англійська

```bash
.venv/bin/python scripts/synthesize_slovak.py \
  --segments work/lesson/reviewed_spans.json \
  --output-dir work/lesson/sk_tts \
  --voice sk-SK-LukasNeural --rate=-8% --concurrency 2

.venv/bin/python scripts/convert_tts_chunks.py \
  --input-dir work/lesson/sk_tts \
  --segments work/lesson/reviewed_spans.json \
  --output-dir work/lesson/sk_converted \
  --language sk --source-voice sk-SK-LukasNeural \
  --source-reference "$DUBBING_SLOVAK_REFERENCE" --extension .wav \
  --runtime "$DUBBING_RUNTIME_SOURCE" --models "$DUBBING_MODELS" \
  --extras "$DUBBING_EXTRAS" --profile oleksii_day1 --threads 2
```

Чистий референсний WAV повинен належати **тому самому базовому голосу**, який читає приклади. Не використовуйте референс Brian для Lukas. Модель з обраною словацькою локаллю не потребує мовного вступу перед короткими словами. Старий варіант із багатомовним Brian і видаленням вступу залишається доступним тільки при явному виборі цього голосу.

Для англійських прикладів запустіть синтез із `--language en --voice en-US-GuyNeural` в окрему папку, а перетворення — з `--language en --source-voice en-US-GuyNeural` та власним чистим англійським референсом. Один вектор базового голосу не застосовується до різних голосів. Тримайте кожне перетворюване висловлювання коротшим за 30 секунд.

На обмеженому CPU доцільно виконувати Holos і OpenVoice послідовно. Розпізнавання довгого запису потребує додаткової пам’яті; короткі частини й менша модель можуть бути потрібні для повного проходу.

## 4. Гучність, складання і звук кімнати

Зберіть вибрані `ID.wav` у спільну приватну папку `speech/`, перевіривши для кожного ID текст, мову й хеш із маніфесту відповідної гілки. Спільний `speech/manifest.json` містить `identity` і словник `segments`. Окремий `assembly.json` повторює перевірені фрагменти з `audio_path`, що вказує на відповідний нормалізований WAV.

```bash
.venv/bin/python scripts/normalize_chunks.py \
  --input-dir work/lesson/speech --output-dir work/lesson/normalized \
  --target-rms 0.065 --peak-ceiling 0.95

.venv/bin/python scripts/assemble_lesson.py \
  --manifest work/lesson/assembly.json --source-duration 1675.819 \
  --natural-timing --output work/lesson/speech_dry.flac \
  --timeline work/lesson/timeline.json
```

Задайте фактичну тривалість власного джерела. Нормалізація застосовує один коефіцієнт на фрагмент; мовлення не прискорюється і не обрізається. Режим `--natural-timing` зберігає початкові проміжки, не доповнюючи коротшу нову фразу тишею. FLAC забезпечує проміжне складання без втрат; MP3 також підтримується.

Для відновлення фону використайте [soundscape.py](docs/SOUNDSCAPE.md). Передавайте сухий голос із тишею у вступі й завершенні: оригінальні немовленнєві частини додає фонова доріжка, щоб вони не дублювалися. Клацання всередині нових фраз зміщуються в часі без розтягування їхніх атак. Фон потрібно перевірити на залишки старого мовлення. Підсумкове вирівнювання гучності й кодування MP3 виконуються після змішування.

## Перевірка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тести перевіряють порядок, часові межі, відсутність обрізання, точне збереження PCM у FLAC і те, що очищення меж не стирає початкову приголосну. Вони не підтверджують переклад або акцент.

Для конкретного уроку потрібні перевірка повноти за джерелом, правильних мовних меж, наголосів і змістових адаптацій; вибіркове повторне розпізнавання; перевірка піків, гучності, початків фраз і фонової доріжки. Остаточна оцінка природності та подібності голосу потребує прослуховування. Нерозбірливі або непідтверджені місця не можна видавати за перевірені носієм.
